# Catatan TKL - Log Sheet & OEE

Aplikasi Log Sheet & OEE untuk TKL Produksi.

## Struktur Folder

```
├── index.html              # Halaman utama aplikasi
├── css/                    # Stylesheet
├── js/                     # JavaScript modules
├── icons/                  # Icon & gambar
├── fonts/                  # Font lokal
├── manifest.webmanifest    # PWA manifest
├── sw.js                   # Service Worker
├── database/               # SQL migration & setup Supabase
├── docs/                   # Dokumentasi
└── scripts-google/         # Google Apps Script
```

## Deployment (Vercel)

Cukup push ke GitHub. Vercel akan otomatis mendeteksi `index.html` di root.

Tidak perlu setting Root Directory lagi.

## Development

Buka `index.html` langsung di browser, atau gunakan Live Server.
